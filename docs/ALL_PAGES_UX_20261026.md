# Shared DSG user experience

The owner requested familiar market-standard UI on every usable page, preserved capabilities, fewer required steps and actual click-through validation. This change puts one navigation, page hierarchy and recovery pattern around the existing application; all existing endpoints, approval roles and provider gates remain.

- Shared root shell covers every owned workspace, enterprise and review route. Workroom retains one chat surface and tools mount when requested; query deep links reopen after hydration and client navigation. Next links preserve the existing module-memory agent SDK; the human approval client remains separate. The drawer stays mounted during navigation and native dialog handles Escape/focus.
- History, usage and follow-up read existing authenticated workspace jobs. Search/filter/paging and the existing result inspector use the loaded records. Failed/malformed reads are distinct from empty data; prior data is labelled stale. Completion status and report existence do not claim provider or signature verification. Original demo views remain explicitly optional. No invented billing/token totals.
- App Builder puts its real console first and offers one next-step action over the existing save/PRD/plan/handoff/runtime-check gates. All manual operations, guides, template registries and readiness panels remain available. New job defaults no longer select retired Vercel deployment: no deployment target is invented.
- Consistent typography, page spacing, visible labels,44px interactive controls, keyboard focus,320px reflow, reduced motion and durable error feedback. Four existing standalone reference pages share keyboard/touch defaults and return navigation. Generated app content/handlers remain; preview navigation, text reflow, contrast, input names and advanced-token masking improve usability.
- Replaced imperative whole-DOM translation with opt-in React copy and a stable server snapshot, retaining the existing Thai/English mappings and stored preference. User text, identifiers, code and generated content are not rewritten.
